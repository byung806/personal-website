# Shared Timeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/memories`, a Couple Joy-style shared timeline (photo cards + milestone rows + date badges + bottom tab bar) inside the existing `personal-website` Next.js app, with unlimited entries and posts from both Bryan and Adela.

**Architecture:** New route (`app/memories/`) and API routes (`app/api/memories/`) added to the existing Next.js 14 App Router site, reusing its existing Postgres database via the existing `lib/prisma` client. Photos upload to Vercel Blob; only URLs are stored in Postgres. Feed refetches on mount and window focus — no websockets/SSE/Firestore.

**Tech Stack:** Next.js 14 (App Router, TypeScript), Prisma + Postgres (existing), Tailwind CSS, lucide-react (existing dependency), `@vercel/blob` (new dependency), `bad-words` (existing dependency, reused for comment moderation).

## Global Constraints

- No Firebase anywhere — Postgres/Prisma + Vercel Blob only.
- No passcode/auth gate in v1 — `/memories` and its API routes are open to anyone with the URL.
- No live realtime push — feed refetches on mount and on `focus`/`visibilitychange` only.
- No `location` field and no map view — the map pin icon in the header is a disabled stub.
- Identity picker offers exactly two choices, "Bryan" and "Adela" — no persistence of the last choice.
- Comments are in scope for v1 (`Comment` model + API + UI).
- Mobile-first layout, `max-width: 480px` centered on desktop.
- Colors and type sizes must match the token table in `docs/superpowers/specs/2026-07-14-shared-timeline-design.md` exactly — implemented as new `timeline-*` Tailwind color tokens (not the sitewide `bg`/`text` tokens, which have different existing meanings).
- `/memories` gets a `noindex` meta tag and must not be linked from `components/navbar.tsx` or any other nav.
- This repo has no automated test suite (verified: no `test` script in `package.json`, no Jest/Vitest config, no existing test files). Follow that convention — every task is verified manually via `npm run dev` + `curl`/browser, not automated tests. Do not introduce a new test framework as part of this plan.
- Repo uses npm (there's a `package-lock.json`, no `yarn.lock`/`pnpm-lock.yaml`) — use `npm install` / `npm run`.

## Pre-Task Setup (manual, one-time, do this before Task 5)

Vercel Blob requires a `BLOB_READ_WRITE_TOKEN` environment variable. This can't be generated by the implementing engineer — it requires access to the Vercel dashboard for this project:

1. In the Vercel dashboard for this project, go to Storage → Create a Blob store (or use an existing one).
2. Connect it to the project. This auto-injects `BLOB_READ_WRITE_TOKEN` for deployed environments.
3. For local dev, run `vercel env pull .env.local` from the repo root (requires the Vercel CLI logged into the right account), or manually copy the token value into `.env.local` as `BLOB_READ_WRITE_TOKEN=...`.

Task 5 (upload route) cannot be manually verified end-to-end without this token present in `.env.local`. Task 5's code can still be written and the dev server will boot without it — only the actual upload call will fail with a clear "missing token" error until this step is done.

- [ ] **Step 2: Write the GET handler**

Create `app/api/memories/route.ts`:

```ts
import { NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';

export async function GET() {
  try {
    const memories = await prisma.memory.findMany({
      orderBy: { date: 'desc' },
      include: {
        photos: { orderBy: { order: 'asc' } },
        _count: { select: { comments: true } },
      },
    });

    const result = memories.map(({ _count, ...memory }) => ({
      ...memory,
      commentCount: _count.comments,
      photoCount: memory.photos.length,
    }));

    return NextResponse.json(result);
  } catch (error) {
    console.error('Error in GET /api/memories:', error);
    return NextResponse.json({ error: 'Failed to fetch memories' }, { status: 500 });
  }
}
```

```tsx
interface MilestoneRowProps {

function daysSince(dateStr: string): number {
  const target = new Date(dateStr);
  const targetUTC = Date.UTC(target.getUTCFullYear(), target.getUTCMonth(), target.getUTCDate());
  const now = new Date();
  const nowUTC = Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate());
  return Math.floor((nowUTC - targetUTC) / 86400000);
}

export default function MilestoneRow({ emoji, title, date }: MilestoneRowProps) {
```

```tsx
'use client';

import { useCallback, useEffect, useState } from 'react';
import TimelineHeader from './components/timeline-header';
import BottomTabBar from './components/bottom-tab-bar';
import DateBadge from './components/date-badge';
import PhotoCard from './components/photo-card';
import MilestoneRow from './components/milestone-row';
import type { MemoryDTO } from './types';

export default function MemoriesView() {
  const [memories, setMemories] = useState<MemoryDTO[] | null>(null);

  const refresh = useCallback(async () => {
    const res = await fetch('/api/memories', { cache: 'no-store' });
    const data: MemoryDTO[] = await res.json();
    setMemories(data);
  }, []);

  useEffect(() => {
    refresh();
    const onFocus = () => refresh();
    window.addEventListener('focus', onFocus);
    document.addEventListener('visibilitychange', onFocus);
    return () => {
      window.removeEventListener('focus', onFocus);
      document.removeEventListener('visibilitychange', onFocus);
    };
  }, [refresh]);

  return (
    <div className="mx-auto flex min-h-screen max-w-[480px] flex-col bg-white">
      <TimelineHeader onAddClick={() => {}} />
      <main className="flex-1 overflow-y-auto px-4 pb-8 pt-6">
        {memories === null && (
          <p className="pt-12 text-center text-[14px] text-timeline-text-secondary">Loading…</p>
        )}
        {memories !== null && memories.length === 0 && (
          <p className="pt-12 text-center text-[14px] text-timeline-text-secondary">
            Nothing here yet — add the first one.
          </p>
        )}
        <div className="flex flex-col gap-8">
          {memories?.map((memory) => (
            <div key={memory.id} className="flex gap-3">
              <DateBadge date={memory.date} />
              <div className="min-w-0 flex-1">
                {memory.type === 'photo' ? (
                  <PhotoCard
                    title={memory.title}
                    emoji={memory.emoji}
                    body={memory.body}
                    photos={memory.photos}
                    commentCount={memory.commentCount}
                    onOpenComments={() => {}}
                  />
                ) : (
                  <MilestoneRow emoji={memory.emoji} title={memory.title} date={memory.date} />
                )}
              </div>
            </div>
          ))}
        </div>
      </main>
      <BottomTabBar />
    </div>
  );
}
```

```ts
import { NextResponse } from 'next/server';
import { put } from '@vercel/blob';

export async function POST(request: Request) {
  try {
    const formData = await request.formData();
    const file = formData.get('file');

    if (!(file instanceof File)) {
      return NextResponse.json({ error: 'No file provided' }, { status: 400 });
    }
    if (!file.type.startsWith('image/')) {
      return NextResponse.json({ error: 'Only image files are allowed' }, { status: 400 });
    }

    const blob = await put(`memories/${Date.now()}-${file.name}`, file, {
      access: 'public',
    });

    return NextResponse.json({ url: blob.url });
  } catch (error) {
    console.error('Error in POST /api/memories/upload:', error);
    return NextResponse.json({ error: 'Failed to upload photo' }, { status: 500 });
  }
}
```

```ts
const AUTHORS = ['bryan', 'adela'];
const TYPES = ['photo', 'milestone'];

export async function POST(request: Request) {
  try {
    const { author, type, title, body, date, emoji, photos } = await request.json();

    if (!AUTHORS.includes(author)) {
      return NextResponse.json({ error: 'Invalid author' }, { status: 400 });
    }
    if (!TYPES.includes(type)) {
      return NextResponse.json({ error: 'Invalid type' }, { status: 400 });
    }
    if (!title || typeof title !== 'string' || title.length > 200) {
      return NextResponse.json({ error: 'Title is required (max 200 chars)' }, { status: 400 });
    }
    if (!date || Number.isNaN(Date.parse(date))) {
      return NextResponse.json({ error: 'A valid date is required' }, { status: 400 });
    }
    if (body && (typeof body !== 'string' || body.length > 1000)) {
      return NextResponse.json({ error: 'Description is too long' }, { status: 400 });
    }
    if (type === 'photo' && (!Array.isArray(photos) || photos.length === 0)) {
      return NextResponse.json({ error: 'At least one photo is required' }, { status: 400 });
    }

    const memory = await prisma.memory.create({
      data: {
        author,
        type,
        title,
        body: body || null,
        date: new Date(date),
        emoji: emoji || null,
        photos: {
          create: (photos ?? []).map((photo: { url: string; order: number }) => ({
            url: photo.url,
            order: photo.order,
          })),
        },
      },
      include: { photos: { orderBy: { order: 'asc' } } },
    });

    return NextResponse.json({ ...memory, commentCount: 0, photoCount: memory.photos.length });
  } catch (error) {
    console.error('Error in POST /api/memories:', error);
    return NextResponse.json({ error: 'Failed to create memory' }, { status: 500 });
  }
}
```

```tsx
import { useState } from 'react';
import { X } from 'lucide-react';
import type { Author, MemoryType } from '../types';

const EMOJI_OPTIONS = ['❤️', '🇫🇷', '✈️', '🎉', '📸', '🏖️', '🎂', '💍', '🌟', '🍕', '🎄', '🐶'];

interface AddMemorySheetProps {
  onClose: () => void;
  onSaved: () => void;
}

export default function AddMemorySheet({ onClose, onSaved }: AddMemorySheetProps) {
  const [author, setAuthor] = useState<Author | null>(null);
  const [type, setType] = useState<MemoryType>('photo');
  const [date, setDate] = useState('');
  const [title, setTitle] = useState('');
  const [emoji, setEmoji] = useState('');
  const [body, setBody] = useState('');
  const [files, setFiles] = useState<File[]>([]);
  const [isSaving, setIsSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const addFiles = (list: FileList | null) => {
    if (!list) return;
    setFiles((prev) => [...prev, ...Array.from(list)]);
  };

  const handleSave = async () => {
    if (!author) {
      setError('Pick who is posting.');
      return;
    }
    if (!title.trim() || !date) {
      setError('Title and date are required.');
      return;
    }
    if (type === 'photo' && files.length === 0) {
      setError('Add at least one photo.');
      return;
    }

    setIsSaving(true);
    setError(null);

    try {
      const uploadedPhotos: { url: string; order: number }[] = [];
      for (const [index, file] of files.entries()) {
        const formData = new FormData();
        formData.append('file', file);
        const uploadRes = await fetch('/api/memories/upload', { method: 'POST', body: formData });
        if (!uploadRes.ok) throw new Error('Photo upload failed.');
        const { url } = await uploadRes.json();
        uploadedPhotos.push({ url, order: index });
      }

        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          author,
          type,
          title: title.trim(),
          body: type === 'photo' ? body.trim() || null : null,
          date,
          emoji: emoji || null,
          photos: uploadedPhotos,
        }),
      });

      if (!createRes.ok) {
        const { error: message } = await createRes.json();
        throw new Error(message ?? 'Failed to save memory.');
      }

      onSaved();
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Something went wrong.');
    } finally {
      setIsSaving(false);
    }
  };

  return (
    <div className="fixed inset-0 z-20 flex items-end justify-center bg-black/40" onClick={onClose}>
      <div
        className="max-h-[85vh] w-full max-w-[480px] overflow-y-auto rounded-t-3xl bg-white p-5"

            <X size={22} />
          </button>
        </div>

        <div className="mt-4 flex gap-2">
          <button
            type="button"
            onClick={() => setAuthor('bryan')}
            className={`flex-1 rounded-xl border px-3 py-2 text-[14px] font-semibold ${
              author === 'bryan' ? 'border-timeline-accent-blue bg-timeline-milestone-bg' : 'border-[#EAEAEA]'
            }`}
          >
            Bryan
          </button>
          <button
            type="button"
            onClick={() => setAuthor('adela')}
            className={`flex-1 rounded-xl border px-3 py-2 text-[14px] font-semibold ${
              author === 'adela' ? 'border-timeline-accent-blue bg-timeline-milestone-bg' : 'border-[#EAEAEA]'
            }`}
          >
            Adela
          </button>
        </div>

        <div className="mt-4 flex gap-2">
          <button
            type="button"
            onClick={() => setType('photo')}
            className={`flex-1 rounded-xl border px-3 py-2 text-[14px] font-semibold ${
              type === 'photo' ? 'border-timeline-accent-blue bg-timeline-milestone-bg' : 'border-[#EAEAEA]'

            Photo memory

            Milestone
          </button>
        </div>

        <label className="mt-4 block text-[13px] font-medium text-timeline-text-secondary">
          Date
          <input
            type="date"
            value={date}
            onChange={(e) => setDate(e.target.value)}
            className="mt-1 w-full rounded-xl border border-[#EAEAEA] px-3 py-2 text-[15px]"
```

```ts
import { NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import { Filter } from 'bad-words';

const filter = new Filter();
const AUTHORS = ['bryan', 'adela'];

export async function GET(_request: Request, { params }: { params: { id: string } }) {
  try {
    const comments = await prisma.comment.findMany({
      where: { memoryId: params.id },
      orderBy: { createdAt: 'asc' },
    });
    return NextResponse.json(comments);
  } catch (error) {
    console.error('Error in GET /api/memories/[id]/comments:', error);
    return NextResponse.json({ error: 'Failed to fetch comments' }, { status: 500 });
  }
}

export async function POST(request: Request, { params }: { params: { id: string } }) {
  try {
    const { author, body } = await request.json();

    if (!AUTHORS.includes(author)) {
      return NextResponse.json({ error: 'Invalid author' }, { status: 400 });
    }
    if (!body || typeof body !== 'string' || body.length > 500) {
      return NextResponse.json({ error: 'Comment is required (max 500 chars)' }, { status: 400 });
    }
    if (filter.isProfane(body)) {
      return NextResponse.json({ error: 'Nice try :)' }, { status: 400 });
    }

    const comment = await prisma.comment.create({
      data: { memoryId: params.id, author, body },
    });

    return NextResponse.json(comment);
  } catch (error) {
    console.error('Error in POST /api/memories/[id]/comments:', error);
    return NextResponse.json({ error: 'Failed to add comment' }, { status: 500 });
  }
}
```
